Admin dashboard · Stage 1

Welcome to the MAFL Sevens admin workspace. Validate your Excel master workbook and preview its record counts before exporting. This first release does not publish directly or write to D1.

Only deploy this page on your Google-protected admin-mafl-sevens Worker. Do not upload these files to the public main branch.

1. Choose your master workbook

Use your MAFL Sevens Master Data Workbook (.xlsx). It must contain Teams, Players, Competitions, Fixtures, Match Performance, and News & Announcements sheets.

An internet connection is needed to load the Excel-reading JavaScript library. Your workbook is not uploaded to a server by this tool.

2. Check the results

Select a workbook to begin.

3. Publish using the existing GitHub workflow

  1. Open your GitHub data folder.
  2. Choose Add file → Upload files while inside the data folder.
  3. Upload the new league.json and commit the change, replacing the old file.
  4. Wait for Cloudflare → Workers & Pages → mafl-sevens → Deployments to show Ready.
  5. Refresh your live website with Ctrl + Shift + R.

Cloudflare Access controls entry to this Worker. Publishing still requires your GitHub account; automatic publishing is not enabled in Stage 1. The workbook is processed in your browser, not sent to our server.

4. Publish to the website (D1)

After validation passes in step 2, save the data as a draft, check the counts, then publish it.
